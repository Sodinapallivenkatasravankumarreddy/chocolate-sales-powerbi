# 🍫 Chocolate Sales Power BI Dashboard

An interactive chocolate sales report built with **Microsoft Power BI**. This repository contains the original Power BI report (`.pbix`) and the report-definition assets extracted from it.

## 📊 Project Overview

The report is designed to explore chocolate sales performance through a collection of Power BI visuals and filters.

The supplied report contains nine pages: a page named **Report** and eight additional pages named **Page 1** through **Page 8**.

The dashboard includes:
- Line charts
- Clustered column and bar charts
- Pie and doughnut charts
- Treemap
- Tables and matrix
- Card visuals
- Interactive slicers

## 📁 Repository Contents

- `BI DASH CHOCO.pbix` — Original Power BI dashboard.
- `powerbi-source/definition/` — Report, page, and visual definition JSON files.
- `powerbi-source/StaticResources/` — Images and shared theme resources.
- `.gitignore` — Git configuration.
- `FILE-MANIFEST.json` — Project file inventory.

## 🚀 How to Open the Dashboard

1. Clone or download this repository.
2. Install Microsoft Power BI Desktop.
3. Open `BI DASH CHOCO.pbix`.
4. Explore the different report pages.
5. Use the available slicers and visual interactions to analyze sales performance.
